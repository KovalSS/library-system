# Конвенція повідомлень комітів

Повідомлення коміту має формат: `<префікс>: <короткий опис зміни>`

| Префікс | Значення |
|---------|----------|
| `spec:` | зміни у специфікації, задумі, вимогах (`/spec`) |
| `test:` | додавання або зміна тестів (`/tests`) |
| `feat:` | зміни у програмному коді, нова функціональність (`/src`) |
| `docs:` | зміни в документації, описах, звітних матеріалах (`/docs`) |
| `gate:` | рішення контрольної точки (вирішення конфлікту, підсумок етапу) |

Кожен коміт стосується одного типу зміни. Якщо зміна зачіпає кілька 
типів артефактів одночасно, коміти розбиваються окремо для кожного типу.
