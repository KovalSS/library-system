# Технологічний стек і каркас проєкту (LS-02)

SRS (розд. 1.3) стек не фіксує; обмеження — веб-застосунок (2.4), мале навантаження
(до 10 одночасних користувачів), обов'язковий TDD (1.4), системний журнал у файл
(REQ-NF-005).

| Призначення | Вибір | Чому |
|---|---|---|
| Мова | Python 3.13 | Інструменти перевірки контракту (лаб. №4) уже на Python |
| HTTP-фреймворк | FastAPI 0.162 | Валідація за схемами (Pydantic), природна відповідність OpenAPI |
| Сховище | SQLite через SQLAlchemy 2.1 | Одна локація, мале навантаження (SRS 2.4); файл БД простий для резервного копіювання (REQ-NF-002) |
| Тести | pytest 9.2 + `TestClient` (httpx) | Тести запитами до застосунку без запуску окремого сервера |
| Логування | стандартний `logging`, запис у файл | REQ-NF-005: часова мітка, рівень, джерело, контекст, `requestId` |

## Структура

```text
src/library/        реалізація (пакет library)
tests/app/          модульні та інтеграційні тести застосунку (pytest)
tests/api/          контрактні сценарії лаб. №4 (mock або реальний сервер)
spec/openapi.yaml   затверджений контракт (API-GATE GO)
var/log/            файли системного журналу під час запуску (не в git)
```

## Команди

| Дія | Команда |
|---|---|
| Встановити залежності | `pip install -r requirements.txt` |
| Запустити тести застосунку | `python -m pytest` |
| Запустити сервер | `python -m uvicorn library.main:app --app-dir src --port 8000` |
| Контрактні сценарії проти сервера | `python tests/api/run.py --base http://127.0.0.1:8000` |
