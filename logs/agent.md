# Запис про кодинговий агент

**Назва інструменту:** Claude Code (Anthropic)

**Клас інструменту:** CLI-агент на основі великої мовної моделі (LLM), 
що працює безпосередньо з файловою системою через термінал.

**Спосіб доступу до репозиторію:** локальний доступ до файлів проєкту 
через командний рядок у робочому каталозі репозиторію; агент не має 
прямого доступу до віддаленого GitHub-репозиторію та не виконує push 
без явної команди користувача.

**Операції, які агент може виконувати:**
- читання та аналіз структури проєкту і вмісту файлів;
- створення, редагування та видалення файлів;
- виконання команд у терміналі (включно з git-командами: add, commit, 
  branch, diff, merge);
- пропозиція змін коду з поясненням.

**Обмеження контролю:** усі запропоновані агентом зміни переглядаються 
користувачем через `git diff` перед комітом; автоматичне прийняття змін 
без перегляду не застосовується.
