## Контрольний запуск реальної системи

Сервер `uvicorn` із чистою БД; основний сценарій етапу 2 через HTTP:
вхід головного адміністратора → створення адміністратора й бібліотекаря →
жанр → видання → екземпляр → реєстрація читача → підтвердження email з листа
(`var/mail/outbox.jsonl`) → вхід читача; плюс три негативні запити.

| Запит | Очікування | Результат |
|---|---|---|
| Основний сценарій (13 запитів) | 200/201 | 200/201 |
| Видання з наявним ISBN | 409 `duplicate_isbn` | 409 `duplicate_isbn` |
| Вхід із невірним паролем | 401 `invalid_credentials` | 401 `invalid_credentials` |
| Читач створює жанр | 403 `forbidden` | 403 `forbidden` |
